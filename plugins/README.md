# macOS Players Plugin for Lampa

Плагин для Lampa, добавляющий поддержку дополнительных плееров на macOS.

## Возможности

- ✅ **Movist Pro** - популярный плеер для macOS
- ✅ **Custom Player** - поддержка любого плеера с настраиваемой URL-схемой
- ✅ Поддержка всех типов плееров: обычный, IPTV, торренты
- ✅ Многоязычность: русский, английский, украинский

## Установка

### Метод 1: Прямая ссылка (рекомендуется)

1. Откройте Lampa
2. Перейдите в **Настройки** → **Расширения**
3. Нажмите **Добавить плагин**
4. Введите URL:
   ```
   https://raw.githubusercontent.com/m1nuzz/lampa/main/plugins/macos-players.js
   ```
5. Нажмите **Добавить**
6. **Перезапустите** Lampa

### Метод 2: Ручной загрузка

1. Скачайте [`macos-players.js`](https://raw.githubusercontent.com/m1nuzz/lampa/main/plugins/macos-players.js)
2. Загрузите файл на ваш сервер или в локальное хранилище
3. Добавьте через **Настройки** → **Расширения**

## Использование

### Movist Pro

1. Установите [Movist Pro](https://movistprime.com/) на ваш macOS
2. В Lampa перейдите в **Настройки** → **Плеер**
3. Выберите **Movist Pro** в настройке:
   - **Тип плеера**
   - **Тип плеера для IPTV**
   - **Тип плеера для торрентов**

### Custom Player

Поддержка любого плеера с URL-схемой:

1. В **Настройки** → **Плеер** выберите **Custom Player**
2. Укажите URL-схему вашего плеера в поле **URL-схема кастомного плеера**

#### Примеры URL-схем:

```
# Простой формат (автоматически добавит encoded URL)
someplayer://open?url=

# Использование плейсхолдеров
mycustomplayer://play?file=${url}      # encoded URL
myplayer://stream?src=${_url}          # URI encoded URL  
player://video?path=${furl}             # полный URL без кодирования
```

#### Поддерживаемые плейсхолдеры:

- `${url}` - URL с полным encodeURIComponent
- `${_url}` - URL с encodeURI
- `${furl}` - полный URL без кодирования

## Примеры настройки для популярных плееров

## Устранение проблем

### Плеер не запускается

1. Убедитесь, что плеер установлен на вашем Mac
2. Проверьте URL-схему в настройках
3. Перезапустите Lampa
4. Очистите кэш браузера

### Custom Player не работает

1. Проверьте формат URL-схемы
2. Убедитесь, что используете правильные плейсхолдеры
3. Попробуйте разные варианты кодирования URL

### Как узнать URL-схему плеера?

1. Проверьте документацию плеера
2. Поищите в файле `Info.plist` плеера (`CFBundleURLSchemes`)
3. Спросите у разработчиков плеера

## Логи и отладка

Откройте консоль разработчика (F12 или Cmd+Option+I) и ищите сообщения с префиксом `[macOS Players Plugin]`.

## Обновление плагина

При использовании прямой ссылки плагин будет автоматически обновляться. Для принудительного обновления:

1. Удалите старый плагин
2. Добавьте его заново
3. Перезапустите Lampa
